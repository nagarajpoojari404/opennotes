Induction head

An induction head is a two-layer attention sub-circuit that completes recurring sequences via pattern matching: given context ... [A] [B] ... [A], it predicts that [B] follows the current [A].

Induction heads are considered the primary mechanistic engine driving in-context learning in Transformers. To implement this algorithm across layers, heads must compose by reading each other’s outputs from the residual stream.

The Algorithmic Goal of an Induction Head

Suppose the input sequence contains:

…[A]⏟i−1 [B]⏟i … [A]⏟j \dots \underbrace{\text{[A]}}_{i-1} \ \underbrace{\text{[B]}}_{i} \ \dots \ \underbrace{\text{[A]}}_{j} …i−1[A]​​ i[B]​​ … j[A]​​

The current token is at position jjj (which is [A]). To predict that [B] comes next, the network must:

  1. Search backward in the context for an earlier occurrence of token [A].
  2. Find the token that immediately followed that earlier [A] (which is [B] at position iii).
  3. Copy [B] to the current prediction at position jjj.

A single attention layer cannot do this on its own:

  • At position iii (where [B] is located), the token [B] has no native awareness that token [A] occurred immediately before it, unless another head or embedding shifted that information into position iii.
  • A 1-layer model can implement a “previous-token head” or a “copy-current-token head”, but it cannot perform “look for previous token matching current token, and extract the next token.”

This requires a circuit consisting of at least two heads across two distinct layers:

  • Head 1 (Layer 0 or early layer): A Previous-Token Head (H1H_1H1​).
  • Head 2 (Layer 1 or downstream layer): An Induction Head (H2H_2H2​).

Step-by-Step: How Induction Heads Work

The standard induction circuit uses K-Composition (or Q-Composition) to set up the attention pattern, followed by the OV circuit to copy the token.

Step 1: Head H1H_1H1​ acts as a Previous-Token Head (Layer 0)

Head H1H_1H1​ attends from position iii to position i−1i-1i−1 (often relying on positional embeddings/RoPE in its QK circuit):

  • At position iii (which holds [B]), H1H_1H1​ reads the representation of [A] from position i−1i-1i−1.
  • H1H_1H1​’s OV circuit writes a vector containing the identity of [A] directly into the residual stream at position iii: xi(1)≈xi(0)+WOV(1)xi−1(0) x_i^{(1)} \approx x_i^{(0)} + W_{OV}^{(1)} x_{i-1}^{(0)} xi(1)​≈xi(0)​+WOV(1)​xi−1(0)​
  • Result: Position iii (token [B]) now carries a tag in the residual stream saying “I was preceded by token [A]”.

Step 2: Head H2H_2H2​ uses K-Composition to Match Queries and Keys (Layer 1)

At the current position jjj, the token is [A]. Head H2H_2H2​’s Query vector at position jjj is computed directly from [A]:

qj=WQ(2)xj≈WQ(2)x[A] q_j = W_Q^{(2)} x_j \approx W_Q^{(2)} x_{\text{[A]}} qj​=WQ(2)​xj​≈WQ(2)​x[A]​

Meanwhile, for all earlier positions iii, Head H2H_2H2​’s Key vector receives the residual stream containing H1H_1H1​’s output via K-composition:

Because xi−1(0)x_{i-1}^{(0)}xi−1(0)​ is also token [A], the combined composition matrix:

When token jjj matches token i−1i-1i−1 (both are [A]), the score spikes positively, causing Head H2H_2H2​ at position jjj to place nearly all its attention weight on position iii (the token [B]).

Step 3: Copying via H2H_2H2​’s OV Circuit

Once H2H_2H2​ attends to position iii, its own Value and Output matrices execute a copying operation:

outputj=WO(2)WV(2)xi \text{output}_j = W_O^{(2)} W_V^{(2)} x_i outputj​=WO(2)​WV(2)​xi​

Since xix_ixi​ holds [B], WOV(2)=WO(2)WV(2)W_{OV}^{(2)} = W_O^{(2)} W_V^{(2)}WOV(2)​=WO(2)​WV(2)​ projects the token embedding of [B] into the direction of the residual stream that the final unembedding matrix (WUW_UWU​) decodes as [B].

Q-Composition vs. K-Composition

Induction heads can be implemented using either mechanism depending on how the model factors the problem:

In empirical circuits research (e.g., in toy models and open LLMs), K-composition is the dominant form observed for induction heads, though mixed variants (both Q- and K-composition active simultaneously) also occur.

Detecting Composition in the Wild

To confirm whether two heads H1H_1H1​ and H2H_2H2​ are actually composing rather than operating independently, interpretability researchers use two quantitative tests:

  1. Path Patching (Activation Patching): Run the model on a repeated sequence [A][B] ... [A]. Intercept the output of H1H_1H1​ entering H2H_2H2​’s KKK-input and replace it with corrupted/random activations. If the model’s ability to predict [B] vanishes, H2H_2H2​ causally depends on H1H_1H1​ via K-composition.
  2. Matrix Norm Metrics: Measure the Frobenius norm of the product matrix: ∥WK(2)WOV(1)∥F \Vert{} W_K^{(2)} W_{OV}^{(1)} \Vert{}_F ∥WK(2)​WOV(1)​∥F​ Compare this against a baseline where the weight matrices are randomly rotated. In true induction heads, the norm is significantly higher than chance, indicating that WK(2)W_K^{(2)}WK(2)​ specifically aligns with the subspace output by WOV(1)W_{OV}^{(1)}WOV(1)​.
