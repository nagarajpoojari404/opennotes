1. Basis & Basis-Free Operations

In mechanistic interpretability, operations within a Transformer are categorized by whether their behavior depends on the coordinate system chosen to represent the vector space:

  • Basis-Free (Rotational Invariance): An operation where rotating the vector space by an orthogonal matrix RRR (R⊤R=IR^\top R = IR⊤R=I) preserves the overall transformation, provided the weights are rotated accordingly.
  • Privileged Basis: An operation where individual coordinate axes (neurons) carry distinct mathematical and semantic meaning that cannot be rotated without breaking the computation.

The Residual Stream is Basis-Free

The residual stream vector x∈Rdmodelx \in \mathbb{R}^{d_{\text{model}}}x∈Rdmodel​ does not have an intrinsic coordinate system. If you rotate the entire residual stream by an orthogonal transformation RRR:

x′=Rx x' = R x x′=Rx

The linear projections of an attention head (WQ,WK,WV,WOW_Q, W_K, W_V, W_OWQ​,WK​,WV​,WO​) adapt simply by multiplying by R⊤R^\topR⊤:

WQ′=WQR⊤,WK′=WKR⊤,WV′=WVR⊤,WO′=RWO W'_Q = W_Q R^\top, \quad W'_K = W_K R^\top, \quad W'_V = W_V R^\top, \quad W'_O = R W_O WQ′​=WQ​R⊤,WK′​=WK​R⊤,WV′​=WV​R⊤,WO′​=RWO​

The internal dot products are preserved:

(WQ′x′)⊤(WK′x′)=(WQR⊤Rx)⊤(WKR⊤Rx)=(WQx)⊤(WKx) (W'_Q x')^\top (W'_K x') = (W_Q R^\top R x)^\top (W_K R^\top R x) = (W_Q x)^\top (W_K x) (WQ′​x′)⊤(WK′​x′)=(WQ​R⊤Rx)⊤(WK​R⊤Rx)=(WQ​x)⊤(WK​x)

Similarly, layer normalization (up to minor coordinate scaling) and linear read/write operations treat all directions symmetrically. There is no special meaning to the kkk-th coordinate of the residual stream.

MLPs Introduce a Privileged Basis

The MLP blocks break rotational symmetry because activation functions (ReLU\text{ReLU}ReLU, GELU\text{GELU}GELU, SwiGLU\text{SwiGLU}SwiGLU) are applied element-wise:

MLP(x)=Wout σ(Winx+bin) \text{MLP}(x) = W_{\text{out}} \ \sigma(W_{\text{in}} x + b_{\text{in}}) MLP(x)=Wout​ σ(Win​x+bin​)

For an arbitrary orthogonal matrix RRR, non-linearities generally do not commute with rotation:

σ(Rz)≠R σ(z) \sigma(R z) \ne R \ \sigma(z) σ(Rz)=R σ(z)

Because σ\sigmaσ evaluates each scalar component along the standard coordinate axes independently:

  1. The hidden layer of an MLP has a privileged basis: the coordinate axes correspond directly to individual neurons.
  2. In contrast, the residual stream lacks a privileged basis, making it harder to assign individual dimensions to discrete features without techniques like Dictionary Learning / Sparse Autoencoders (SAEs).

2. Superposition

Superposition is the phenomenon where a neural network represents significantly more independent features than it has dimensions (M≫dM \gg dM≫d).

The Geometric Mechanism

If features were strictly orthogonal, a ddd-dimensional space could represent at most ddd features without mutual interference. However, in high dimensions, an exponentially large number of vectors can be almost orthogonal (a consequence of the Johnson-Lindenstrauss lemma and high-dimensional sphere packing):

⟨vi,vj⟩≈0for i≠j \langle v_i, v_j \rangle \approx 0 \quad \text{for } i \ne j ⟨vi​,vj​⟩≈0for i=j

When a model maps MMM features {fi}i=1M\{f_i\}_{i=1}^M{fi​}i=1M​ with activations ai≥0a_i \ge 0ai​≥0 into a ddd-dimensional space via unit feature directions vi∈Rdv_i \in \mathbb{R}^dvi​∈Rd:

x=∑i=1Maivi x = \sum_{i=1}^M a_i v_i x=i=1∑M​ai​vi​

To decode feature kkk, we project xxx onto vkv_kvk​:

a^k=⟨vk,x⟩=ak+∑i≠kai⟨vk,vi⟩ \hat{a}_k = \langle v_k, x \rangle = a_k + \sum_{i \ne k} a_i \langle v_k, v_i \rangle a^k​=⟨vk​,x⟩=ak​+i=k∑​ai​⟨vk​,vi​⟩

The second term ∑i≠kai⟨vk,vi⟩\sum_{i \ne k} a_i \langle v_k, v_i \rangle∑i=k​ai​⟨vk​,vi​⟩ acts as interference noise (crosstalk).

Why Superposition Works: Sparsity

Superposition is computationally viable when real-world features are sparse—meaning only a tiny fraction of features ai>0a_i > 0ai​>0 fire simultaneously for any single input:

  1. If most ai=0a_i = 0ai​=0, the sum of interference noise remains small.
  2. Non-linear thresholding (e.g., ReLU\text{ReLU}ReLU) can clear out small interference ripples: ReLU(a^k−τ)≈ak \text{ReLU}(\hat{a}_k - \tau) \approx a_k ReLU(a^k​−τ)≈ak​

Polysemanticity

Superposition directly causes polysemanticity: because feature directions are not aligned with standard basis vectors, individual neurons (the basis vectors) end up projecting onto multiple unrelated feature directions. Inspecting a single neuron activation reveals that it activates for multiple distinct, unrelated concepts.

3. Double Descent

Double descent is a generalization phenomenon that reconciles classical statistical learning theory with the empirical success of deep, overparameterized neural networks.

   ```

Risk / Test Error | | Underfitting Interpolation Peak | \ /
| \ /
| Classical \ Overfitting/ \ Modern Overparameterized | U-Curve \ Spike / \ Regime | \ / -—————– | _______/ +————————————————————> Capacity / Parameters (p) p = n

Classical Regime (p<np < np<n)

  • In classical statistics, as model capacity (number of parameters ppp) increases relative to the number of training samples nnn, bias decreases while variance increases.
  • The test error exhibits the standard U-shaped curve, reaching an optimal trade-off point and then increasing due to overfitting as p→np \to np→n.

The Interpolation Threshold (p=np = np=n)

  • At the interpolation boundary where model capacity just barely matches the training set size, the model fits the training data and noise with zero training loss.
  • To fit noisy training labels exactly without excess capacity, the model must contort its decision boundary violently (large norm solutions), driving the variance to its maximum. This causes a pronounced spike in test error.

Modern Overparameterized Regime (p≫np \gg np≫n)

  • When capacity extends well beyond the interpolation point (p≫np \gg np≫n), there are infinitely many parameter configurations that achieve zero training error.
  • Optimizers like Stochastic Gradient Descent (SGD) implicitly regularize the solution by selecting the interpolating function with the minimum norm (e.g., minimum L2L_2L2​ norm in weights): w∗=arg⁡min⁡w∥w∥s.t.Xw=y w^* = \arg\min_w \Vert{}w\Vert{} \quad \text{s.t.} \quad Xw = y w∗=argwmin​∥w∥s.t.Xw=y
  • As parameter count increases further, the space of zero-loss interpolators expands, allowing SGD to find smoother, lower-norm functions that interpolate the training points while generalizing effectively.

Double descent manifests across three primary dimensions:

  1. Model-wise Double Descent: Varying the width or depth of the architecture.
  2. Epoch-wise Double Descent: Prolonged training where error drops, rises, and drops again.
  3. Sample-wise Double Descent: Varying dataset size nnn for a fixed model size ppp.
