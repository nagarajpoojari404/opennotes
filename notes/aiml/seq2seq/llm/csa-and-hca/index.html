CSA and HCA

Compressed Sparse Attention (CSA) is an attention architecture introduced in DeepSeek-V4 designed to scale sequence context to massive lengths (1M+ tokens) while addressing both the compute bottleneck and the KV-cache memory capacity bottleneck.

While standard DeepSeek Sparse Attention (DSA) solves compute complexity by selecting a top-kkk subset of past tokens, the KV cache still scales linearly with the sequence length (O(L)O(L)O(L) cache capacity). CSA combines sequence compression with dynamic sparse routing to slash both memory footprint and FLOPs.

Core Idea: Dual-Stage Efficiency

CSA operates through a two-step reduction:

  1. Token Pooling / KV Compression (m:1m:1m:1): Adjacent tokens along the sequence dimension are compressed into compact, pooled KV blocks using learned weights. Outcome School
  2. Dynamic Sparse Selection (Top-k\text{Top-}kTop-k): Instead of evaluating full attention over all compressed blocks, a lightweight Lightning Indexer scores the compressed entries and routes attention only to the top-kkk most relevant blocks. Outcome School
Raw Tokens (L) 
    │
    ▼ [Learned Overlapping Pooling (m:1)]
Compressed KV Blocks (L / m)
    │
    ▼ [Lightning Indexer Scoring + Top-k Selection]
Sparse High-Precision Attention (k blocks)

Mathematical Mechanism

1. Overlapping KV Compression

Rather than doing naive downsampling or non-overlapping striding (which causes sharp information loss at boundaries), CSA performs overlapping sequence pooling.

Architectural Context: CSA vs. HCA

Outcome School

In architectures like DeepSeek-V4, CSA is typically interleaved with Heavily Compressed Attention (HCA):

Outcome School

Attention TypeCompression Ratio (mmm)Selection StrategyAttention DensityPurpose
CSAMild (m=4m=4m=4)Dynamic Top-kkk via IndexerSparseHigh-detail retrieval over relevant history.
HCAAggressive (m′=128m'=128m′=128)None (No indexer)DenseGlobal background context with near-zero cache footprint.

Summary of Benefits

  • Reduced KV Footprint: Compressing mmm tokens into 1 entry shrinks the physical memory consumption of the KV cache by m×m\timesm×. Outcome School
  • Sub-linear Scaling: With kkk fixed (e.g., k≪L/mk \ll L/mk≪L/m), the computational cost of the main attention core scales with O(k⋅d)O(k \cdot d)O(k⋅d) instead of O(L⋅d)O(L \cdot d)O(L⋅d).
  • No Boundary Artifacts: The 2m2m2m overlapping softmax pooling prevents rigid chunking boundaries from destroying local syntactic and semantic cohesion.
