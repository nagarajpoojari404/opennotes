Training mem cost

During LLM pretraining, memory overhead is divided into static state memory (model weights, gradients, optimizer states), dynamic activation memory, and runtime buffers/fragmentation.

3. Dynamic Activation Memory

Activation memory scales with batch size per GPU (bbb), sequence length (sss), number of transformer layers (LLL), and hidden dimension (hhh).

  • Without Activation Checkpointing:

    Mact≈b⋅s⋅L⋅h⋅(34+5⋅a⋅sh) bytesM_{\text{act}} \approx b \cdot s \cdot L \cdot h \cdot \left(34 + 5 \cdot \frac{a \cdot s}{h}\right) \text{ bytes}Mact​≈b⋅s⋅L⋅h⋅(34+5⋅ha⋅s​) bytes

  • With Selective Activation Recomputation (FlashAttention-2 / 3): Retains only intermediate layer inputs and recomputes attention maps on the fly:

    Mact≈2⋅b⋅s⋅L⋅h bytesM_{\text{act}} \approx 2 \cdot b \cdot s \cdot L \cdot h \text{ bytes}Mact​≈2⋅b⋅s⋅L⋅h bytes

    Mact≈2⋅(2)⋅(4096)⋅(32)⋅(4096)⋅2≈4.29 GBM_{\text{act}} \approx 2 \cdot (2) \cdot (4096) \cdot (32) \cdot (4096) \cdot 2 \approx \mathbf{4.29\text{ GB}}Mact​≈2⋅(2)⋅(4096)⋅(32)⋅(4096)⋅2≈4.29 GB

Activation memory is the temporary GPU RAM used to store the intermediate tensors produced during the forward pass so that gradients can be computed via the chain rule during the backward pass.

1. Why Activations Are Stored

For any linear or matrix operation Y=X⋅WY = X \cdot WY=X⋅W:

  • The forward pass computes YYY.

  • The backward pass needs to compute the gradient with respect to weights:

    ∂L∂W=XT⋅∂L∂Y\frac{\partial \mathcal{L}}{\partial W} = X^T \cdot \frac{\partial \mathcal{L}}{\partial Y}∂W∂L​=XT⋅∂Y∂L​

    To evaluate that product, the input tensor XXX must remain in memory until the backward pass reaches that layer.

2. The Analytical Formula (Without Checkpointing)

For a standard transformer layer, activations are stored at each operation: Attention (Q, K, V projections, attention matrix, softmax, output projection), Feed-Forward Network (FFN/MLP), LayerNorms/RMSNorms, and residual additions.

For a model with:

  • bbb = micro-batch size per GPU

  • sss = sequence length (context window)

  • hhh = hidden dimension

  • aaa = number of attention heads (where head dimension d=h/ad = h / ad=h/a)

  • Precision: 16-bit floating point (2 bytes per element2\text{ bytes per element}2 bytes per element)

Summing across all operations in one layer gives:

Mlayer≈b⋅s⋅h⋅(34+5⋅a⋅sh) bytesM_{\text{layer}} \approx b \cdot s \cdot h \cdot \left(34 + 5 \cdot \frac{a \cdot s}{h}\right) \text{ bytes}Mlayer​≈b⋅s⋅h⋅(34+5⋅ha⋅s​) bytes

Multiplying by the total number of layers LLL:

Mact≈b⋅s⋅L⋅h⋅(34+5⋅a⋅sh) bytesM_{\text{act}} \approx b \cdot s \cdot L \cdot h \cdot \left(34 + 5 \cdot \frac{a \cdot s}{h}\right) \text{ bytes}Mact​≈b⋅s⋅L⋅h⋅(34+5⋅ha⋅s​) bytes

Notice two distinct terms inside the parentheses:

  1. 343434 (Linear scaling with sss): Hidden state projections, norms, and FFN expansions (O(s)O(s)O(s)).

  2. 5⋅ash5 \cdot \frac{as}{h}5⋅has​ (Quadratic scaling with sss): Storing the raw s×ss \times ss×s attention matrices and softmax maps (O(s2)O(s^2)O(s2)).

3. How Checkpointing and FlashAttention Change This

Because storing every intermediate tensor causes memory to grow linearly with layer depth LLL and quadratically with context length s2s^2s2, modern training uses two primary optimizations:

A. Full Activation Checkpointing (Rematerialization)

  • Mechanism: Discards all intermediate activations inside each transformer block after the forward pass, retaining only the single input tensor entering each layer (b×s×hb \times s \times hb×s×h).

  • During Backward: Re-executes the forward pass for that block on-the-fly to regenerate the necessary activations.

  • Trade-off: Adds ~30–33% compute overhead (one extra forward pass), but reduces activation memory from O(L⋅s2)O(L \cdot s^2)O(L⋅s2) down to roughly:

    Mact≈2⋅b⋅s⋅L⋅h bytesM_{\text{act}} \approx 2 \cdot b \cdot s \cdot L \cdot h \text{ bytes}Mact​≈2⋅b⋅s⋅L⋅h bytes

B. FlashAttention (Tiling & Online Softmax)

  • Mechanism: Fuses the attention calculation into a single GPU SRAM kernel using online softmax. It never writes the large b×a×s×sb \times a \times s \times sb×a×s×s attention matrix to high-bandwidth memory (HBM).

  • Impact: Eliminates the quadratic O(s2)O(s^2)O(s2) memory term entirely, making attention memory scale strictly linear with sequence length sss.
