Attention

Attention mechanisms can be organized into six structural paradigms: classical scoring alignments, routing configurations, KV-cache parameter sharing, sparse & linear asymptotic reductions, hardware-aware tiling engines, and hierarchical multi-scale compressed attentions (including DeepSeek’s recent architectures).

1. Mathematical Scoring Functions (Compatibility Metrics)

Given query q∈Rdkq \in \mathbb{R}^{d_k}q∈Rdk​ and key k∈Rdkk \in \mathbb{R}^{d_k}k∈Rdk​:

  • Additive / Concat Attention (Bahdanau et al.): eij=vaTtanh⁡(Wqqi+Wkkj) e_{ij} = v_a^T \tanh(W_q q_i + W_k k_j) eij​=vaT​tanh(Wq​qi​+Wk​kj​) Maps queries and keys into a shared latent space before projecting down to a scalar via vav_ava​. High expressivity, but non-vectorized addition makes it memory-bound on tensor cores.
  • General / Bilinear Attention (Luong et al.): eij=qiTWakj e_{ij} = q_i^T W_a k_j eij​=qiT​Wa​kj​ Uses a learnable matrix Wa∈Rdq×dkW_a \in \mathbb{R}^{d_q \times d_k}Wa​∈Rdq​×dk​ to model asymmetric cross-correlation between different latent dimensions.
  • Scaled Dot-Product Attention (Vaswani et al.): Attention(Q,K,V)=softmax(QKTdk+M)V \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V Attention(Q,K,V)=softmax(dk​​QKT​+M)V The dk\sqrt{d_k}dk​​ divisor stabilizes variance at ≈1\approx 1≈1, preventing the softmax distribution from saturating with near-zero gradients at large dimensions.
  • Cosine / Scaled-Cosine Attention: eij=qi⋅kj∥qi∥2∥kj∥2⋅τ e_{ij} = \frac{q_i \cdot k_j}{\Vert{}q_i\Vert{}_2 \Vert{}k_j\Vert{}_2 \cdot \tau} eij​=∥qi​∥2​∥kj​∥2​⋅τqi​⋅kj​​ Normalizes vector norms and scales by learnable temperature τ\tauτ. Used in Swin Transformer v2 and vision transformers to prevent extreme logit drift.

2. Contextual Routing & Information Flow

  • Self-Attention: Q,K,VQ, K, VQ,K,V are projected from the same hidden sequence H∈RN×dH \in \mathbb{R}^{N \times d}H∈RN×d. Computes intra-sequence token interaction.
  • Cross-Attention: QQQ originates from target sequence HdecH_{\text{dec}}Hdec​, while K,VK, VK,V originate from source sequence HencH_{\text{enc}}Henc​: Q=HdecWQ,K=HencWK,V=HencWV Q = H_{\text{dec}} W_Q, \quad K = H_{\text{enc}} W_K, \quad V = H_{\text{enc}} W_V Q=Hdec​WQ​,K=Henc​WK​,V=Henc​WV​
  • Causal Masking: Imposes Mij=−∞M_{ij} = -\inftyMij​=−∞ for j>ij > ij>i. Enforces autoregressive token dependency (p(xt∣x<t)p(x_t \mid x_{\lt t})p(xt​∣x<t​)).
  • Sliding Window / Local Banded Attention: Mij={0∣i−j∣≤w−∞otherwise M_{ij} = \begin{cases} 0 & \vert{}i - j\vert{} \le w \\ -\infty & \text{otherwise} \end{cases} Mij​={0−∞​∣i−j∣≤wotherwise​ Restricts computation to a local neighborhood of radius www, dropping complexity from O(N2)O(N^2)O(N2) to O(N⋅w)O(N \cdot w)O(N⋅w).

Multi-Head Latent Attention (MLA)

MLA compresses the KV cache into a low-rank latent vector ctKV∈Rdc\mathbf{c}_t^{KV} \in \mathbb{R}^{d_c}ctKV​∈Rdc​ (where dc≪dh⋅nhd_c \ll d_h \cdot n_hdc​≪dh​⋅nh​), eliminating the need to store full uncompressed key and value vectors:

ctKV=WDKVht,ktC=WUKctKV,vtC=WUVctKV \mathbf{c}_t^{KV} = W^{DKV} h_t, \quad k_t^C = W^{UK} \mathbf{c}_t^{KV}, \quad v_t^C = W^{UV} \mathbf{c}_t^{KV} ctKV​=WDKVht​,ktC​=WUKctKV​,vtC​=WUVctKV​

Because Rotary Position Embedding (RoPE) cannot be applied directly to low-rank compressed keys without breaking matrix associativity during decoding, MLA uses a decoupled RoPE strategy:

qt,i=[WUQctQ;RoPE(WQRctQ)],kt,i=[ktC;RoPE(WKRht)] q_{t, i} = [W^{UQ} \mathbf{c}_t^Q; \text{RoPE}(W^{QR} \mathbf{c}_t^Q)], \quad k_{t, i} = [k_t^C; \text{RoPE}(W^{KR} h_t)] qt,i​=[WUQctQ​;RoPE(WQRctQ​)],kt,i​=[ktC​;RoPE(WKRht​)]

During inference, WUKW^{UK}WUK can be absorbed directly into WUQW^{UQ}WUQ, allowing the model to compute attention directly over the compressed cache cKV\mathbf{c}^{KV}cKV.

4. DeepSeek & Frontier Multi-Scale / Sparse Attentions

To scale context windows to 1M+ tokens without unbounded compute or KV-cache explosion, recent architectures move toward multi-tiered memory systems.

Raw Token Stream (Length N)
   │
   ├── Recent Context (Sliding Window: raw uncompressed tokens)
   │
   ├── Medium-Range Context (CSA: Compressed 4:1 + Learned Top-k Selection via DSA)
   │
   └── Distant Context (HCA: Heavily Compressed 128:1 + Dense Attention)

A. DeepSeek Sparse Attention (DSA)

Instead of attending across all visible tokens or relying on fixed static heuristics, DSA employs an auxiliary lightweight indexer to dynamically select a sparse subset of token blocks:

  1. A small projection scores relevance between query qtq_tqt​ and cached block representations bjb_jbj​: stj=ReLU(qtWidxbj) s_{tj} = \text{ReLU}(q_t W_{\text{idx}} b_j) stj​=ReLU(qt​Widx​bj​)
  2. Only the Top-kkk scoring blocks are retrieved: St=Top-k({stj}j=1B) \mathcal{S}_t = \text{Top-}k(\{s_{tj}\}_{j=1}^B) St​=Top-k({stj​}j=1B​)
  3. Full scaled dot-product attention executes solely over tokens in index set St\mathcal{S}_tSt​: Outputt=Attention(qt,K[St],V[St]) \text{Output}_t = \text{Attention}\left(q_t, K_{[\mathcal{S}_t]}, V_{[\mathcal{S}_t]}\right) Outputt​=Attention(qt​,K[St​]​,V[St​]​)

B. Compressed Sparse Attention (CSA)

CSA compresses blocks of adjacent tokens into single compressed KV representations before sparse selection.

  • Given block size mmm (typically m=4m=4m=4), adjacent tokens are pooled via learned saliency weighting: Medium K~b=∑j∈blockbαjKj,V~b=∑j∈blockbαjVj \tilde{K}_b = \sum_{j \in \text{block}_b} \alpha_j K_j, \quad \tilde{V}_b = \sum_{j \in \text{block}_b} \alpha_j V_j K~b​=j∈blockb​∑​αj​Kj​,V~b​=j∈blockb​∑​αj​Vj​
  • The model executes DSA-style sparse index selection over the compressed blocks K~,V~\tilde{K}, \tilde{V}K~,V~, reducing both KV memory footprint and token selection overhead.

C. Heavily Compressed Attention (HCA)

For distant context where fine-grained syntactic details blur into macroscopic semantics, HCA applies an aggressive compression factor m′≫mm' \gg mm′≫m (e.g., m′=64m' = 64m′=64 or 128128128):

KHCA=Poolm′(K),VHCA=Poolm′(V) K^{\text{HCA}} = \text{Pool}_{m'}(K), \quad V^{\text{HCA}} = \text{Pool}_{m'}(V) KHCA=Poolm′​(K),VHCA=Poolm′​(V)

Because a 1M-token sequence is compressed down to ≈7,800\approx 7,800≈7,800 tokens, dense attention can be evaluated over the entire distant history without sparse top-kkk filtering, maintaining global receptive field at minimal FLOP cost.

5. Linear & Kernelized Attention Approximations (O(N)O(N)O(N))

Standard attention scales quadratically (O(N2)O(N^2)O(N2)) due to the N×NN \times NN×N matrix. Linear variants eliminate softmax to exploit associative multiplication.

  • Linearized Attention via Feature Maps (Katharopoulos et al.): Using a non-negative feature map ϕ(x)=elu(x)+1\phi(x) = \text{elu}(x) + 1ϕ(x)=elu(x)+1: Sim(Q,K)=ϕ(Q)ϕ(K)T \text{Sim}(Q, K) = \phi(Q)\phi(K)^T Sim(Q,K)=ϕ(Q)ϕ(K)T By matrix associativity: Attention(Q,K,V)=ϕ(Q)(ϕ(K)TV)ϕ(Q)(ϕ(K)T1N) \text{Attention}(Q,K,V) = \frac{\phi(Q)\left(\phi(K)^T V\right)}{\phi(Q)\left(\phi(K)^T \mathbf{1}_N\right)} Attention(Q,K,V)=ϕ(Q)(ϕ(K)T1N​)ϕ(Q)(ϕ(K)TV)​ Computing (ϕ(K)TV)∈Rd×d(\phi(K)^T V) \in \mathbb{R}^{d \times d}(ϕ(K)TV)∈Rd×d first drops complexity from O(N2d)O(N^2 d)O(N2d) to O(Nd2)O(N d^2)O(Nd2).
  • Performer / FAVOR+ (Random Feature Attention): Uses orthogonal random projections ωi∼N(0,I)\omega_i \sim \mathcal{N}(0, I)ωi​∼N(0,I) to approximate the exponential softmax kernel without non-negativity breakdown: ϕ(x)=h(x)M[exp⁡(ω1Tx−∥x∥22),…,exp⁡(ωMTx−∥x∥22)]T \phi(x) = \frac{h(x)}{\sqrt{M}} \left[ \exp\left(\omega_1^T x - \frac{\Vert{}x\Vert{}^2}{2}\right), \dots, \exp\left(\omega_M^T x - \frac{\Vert{}x\Vert{}^2}{2}\right) \right]^T ϕ(x)=M​h(x)​[exp(ω1T​x−2∥x∥2​),…,exp(ωMT​x−2∥x∥2​)]T
  • Linformer (Low-Rank Projection): Projects key and value sequence length dimensions from NNN down to fixed dimension kkk using linear matrices E,F∈Rk×NE, F \in \mathbb{R}^{k \times N}E,F∈Rk×N: Kˉ=EK∈Rk×d,Vˉ=FV∈Rk×d \bar{K} = E K \in \mathbb{R}^{k \times d}, \quad \bar{V} = F V \in \mathbb{R}^{k \times d} Kˉ=EK∈Rk×d,Vˉ=FV∈Rk×d Attention(Q,Kˉ,Vˉ)=softmax(QKˉTdk)Vˉ  ⟹  O(N⋅k) \text{Attention}(Q, \bar{K}, \bar{V}) = \text{softmax}\left(\frac{Q \bar{K}^T}{\sqrt{d_k}}\right)\bar{V} \implies O(N \cdot k) Attention(Q,Kˉ,Vˉ)=softmax(dk​​QKˉT​)Vˉ⟹O(N⋅k)

6. Hardware-Aware Exact Attention (Tiling & IO-Aware)

These methods compute standard scaled dot-product attention without mathematical approximation, restructuring operations to optimize data movement between GPU SRAM (fast, small) and High Bandwidth Memory (HBM, slow, large).

  • FlashAttention (Online Softmax Tiling): Standard softmax requires computing ∑jesj\sum_j e^{s_j}∑j​esj​ across the entire row before dividing. Online softmax computes incremental normalizers over tiles BcB_cBc​ and BrB_rBr​: mnew=max⁡(mold,max⁡(Stile)),ℓnew=emold−mnewℓold+∑eStile−mnew m_{\text{new}} = \max(m_{\text{old}}, \max(S_{\text{tile}})), \quad \ell_{\text{new}} = e^{m_{\text{old}} - m_{\text{new}}} \ell_{\text{old}} + \sum e^{S_{\text{tile}} - m_{\text{new}}} mnew​=max(mold​,max(Stile​)),ℓnew​=emold​−mnew​ℓold​+∑eStile​−mnew​ Onew=diag(emold−mnew)Oold+eStile−mnewVtile O_{\text{new}} = \text{diag}\left(e^{m_{\text{old}} - m_{\text{new}}}\right) O_{\text{old}} + e^{S_{\text{tile}} - m_{\text{new}}} V_{\text{tile}} Onew​=diag(emold​−mnew​)Oold​+eStile​−mnew​Vtile​ Never writes the N×NN \times NN×N attention matrix to HBM.
  • FlashDecoding & FlashDecoding++: Splits the KV cache along the sequence dimension into independent chunks during autoregressive generation (M=1,N=largeM=1, N=\text{large}M=1,N=large). Computes partial attention sums concurrently in SRAM across multiple streaming multiprocessors (SMs), followed by a fast final reduction.
  • PagedAttention (vLLM): Treats the KV cache as virtual memory pages. Allocates fixed-sized memory blocks on demand, eliminating internal fragmentation and supporting zero-copy beam search / prefix caching.
