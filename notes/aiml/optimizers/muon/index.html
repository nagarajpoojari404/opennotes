Muon

Muon (Momentum Orthogonalized by Newton-schulz) is an optimizer tailored for 2D weight matrices (linear and dense layers) in neural networks. Where standard SGD operates in Euclidean/Frobenius geometry and Adam normalizes coordinate-wise (inducing an ℓ∞\ell_\inftyℓ∞​-like update), Muon treats weights as linear operators and restricts updates under the spectral norm.

1. The Variational Formulation: Steepest Descent on Spectral Ball

Let a weight matrix be W∈Rdout×dinW \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}W∈Rdout​×din​ and let G=∇WLG = \nabla_W \mathcal{L}G=∇W​L be its objective gradient (or momentum buffer).

We seek an update ΔW\Delta WΔW that maximizes descent in the first-order Taylor expansion while constraining the spectral norm ∥ΔW∥2≤1\Vert{}\Delta W\Vert{}_2 \le 1∥ΔW∥2​≤1 (the maximum operator stretch):

ΔW∗=arg⁡min⁡∥ΔW∥2≤1⟨G,ΔW⟩=arg⁡min⁡∥ΔW∥2≤1Tr⁡(G⊤ΔW) \Delta W^* = \arg\min_{\Vert{}\Delta W\Vert{}_2 \le 1} \langle G, \Delta W \rangle = \arg\min_{\Vert{}\Delta W\Vert{}_2 \le 1} \operatorname{Tr}(G^\top \Delta W) ΔW∗=arg∥ΔW∥2​≤1min​⟨G,ΔW⟩=arg∥ΔW∥2​≤1min​Tr(G⊤ΔW)

Derivation via Singular Value Decomposition (SVD)

Let the singular value decomposition of GGG be:

G=UΣV⊤=∑i=1rσiuivi⊤,σ1≥σ2≥⋯≥σr>0 G = U \Sigma V^\top = \sum_{i=1}^{r} \sigma_i u_i v_i^\top, \quad \sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0 G=UΣV⊤=i=1∑r​σi​ui​vi⊤​,σ1​≥σ2​≥⋯≥σr​>0

By Von Neumann’s trace inequality and Hölder’s inequality for Schatten norms (since ∥⋅∥2=∥⋅∥S∞\Vert{}\cdot\Vert{}_2 = \Vert{}\cdot\Vert{}_{S_\infty}∥⋅∥2​=∥⋅∥S∞​​ is dual to the nuclear norm ∥⋅∥∗=∥⋅∥S1\Vert{}\cdot\Vert{}_* = \Vert{}\cdot\Vert{}_{S_1}∥⋅∥∗​=∥⋅∥S1​​):

Tr⁡(G⊤ΔW)≥−∑i=1rσi(G)σi(ΔW) \operatorname{Tr}(G^\top \Delta W) \ge -\sum_{i=1}^{r} \sigma_i(G) \sigma_i(\Delta W) Tr(G⊤ΔW)≥−i=1∑r​σi​(G)σi​(ΔW)

Because ∥ΔW∥2≤1\Vert{}\Delta W\Vert{}_2 \le 1∥ΔW∥2​≤1, each singular value σi(ΔW)≤1\sigma_i(\Delta W) \le 1σi​(ΔW)≤1. The lower bound is achieved when all σi(ΔW)=1\sigma_i(\Delta W) = 1σi​(ΔW)=1 aligned along the singular vectors of GGG:

ΔW∗=−UV⊤ \Delta W^* = - U V^\top ΔW∗=−UV⊤

UV⊤U V^\topUV⊤ is the polar factor (orthogonal projection) of GGG. Instead of letting a few large singular values dominate step sizes, Muon flattens all non-zero singular values to 111, allowing updates along all active spectral directions equally.

2. Fast Orthogonalization via Newton–Schulz Iteration

Computing the exact SVD via Golub-Kahan per step is O(min⁡(din,dout)3)O(\min(d_{\text{in}}, d_{\text{out}})^3)O(min(din​,dout​)3), which is prohibitively slow on GPUs. Muon approximates UV⊤UV^\topUV⊤ using a polynomial Newton–Schulz iteration consisting purely of matrix multiplications.

Assume without loss of generality that X∈Rn×mX \in \mathbb{R}^{n \times m}X∈Rn×m is wide (n≤mn \le mn≤m; if tall, transpose first).

  1. Initial Frobenius normalization: X0=G∥G∥F+ϵ X_0 = \frac{G}{\Vert{}G\Vert{}_F + \epsilon} X0​=∥G∥F​+ϵG​ Since ∥G∥F=∑σi2≥σmax⁡(G)\Vert{}G\Vert{}_F = \sqrt{\sum \sigma_i^2} \ge \sigma_{\max}(G)∥G∥F​=∑σi2​​≥σmax​(G), this guarantees that every singular value σi(X0)≤1\sigma_i(X_0) \le 1σi​(X0​)≤1.
  2. Odd polynomial iteration (Quintic form): Xk+1=aXk+b(XkXk⊤)Xk+c(XkXk⊤)2Xk X_{k+1} = a X_k + b (X_k X_k^\top) X_k + c (X_k X_k^\top)^2 X_k Xk+1​=aXk​+b(Xk​Xk⊤​)Xk​+c(Xk​Xk⊤​)2Xk​ Evaluating on singular values, this applies a 1D mapping ϕ(σ)=aσ+bσ3+cσ5\phi(\sigma) = a\sigma + b\sigma^3 + c\sigma^5ϕ(σ)=aσ+bσ3+cσ5 to every singular value while leaving the singular vectors U,VU, VU,V unchanged. With tuned coefficients: a=3.4445,b=−4.7750,c=2.0315 a = 3.4445, \quad b = -4.7750, \quad c = 2.0315 a=3.4445,b=−4.7750,c=2.0315 The function ϕ(σ)\phi(\sigma)ϕ(σ) rapidly drives all σ∈(0,1]\sigma \in (0, 1]σ∈(0,1] toward the fixed point σ∗=1\sigma^* = 1σ∗=1 in typically 555 iterations: O=NewtonSchulz(X0,k=5)≈UV⊤ O = \text{NewtonSchulz}(X_0, k=5) \approx U V^\top O=NewtonSchulz(X0​,k=5)≈UV⊤

3. Complete Muon Update Algorithm

Muon integrates standard Nesterov momentum and adjusts for rectangular matrix geometries:

  1. Momentum accumulation: Mt=βMt−1+(1−β)Gt M_t = \beta M_{t-1} + (1 - \beta) G_t Mt​=βMt−1​+(1−β)Gt​
  2. Nesterov blend: M~t=(1−β)Gt+βMt \widetilde{M}_t = (1 - \beta) G_t + \beta M_t Mt​=(1−β)Gt​+βMt​
  3. Newton–Schulz orthogonalization: Ot=NewtonSchulz(M~t) O_t = \text{NewtonSchulz}(\widetilde{M}_t) Ot​=NewtonSchulz(Mt​)
  4. Aspect ratio scaling: For an n×mn \times mn×m matrix, an orthogonal matrix has entries scaling as O(1/max⁡(n,m))O(1/\sqrt{\max(n, m)})O(1/max(n,m)​). To maintain uniform Root-Mean-Square (RMS) parameter update magnitudes across arbitrary layer dimensions, the update is scaled by: γ=max⁡(1,nm) \gamma = \sqrt{\max\left(1, \frac{n}{m}\right)} γ=max(1,mn​)​
  5. Weight update with decoupled decay: Wt+1=Wt−ηt(γOt+λWt) W_{t+1} = W_t - \eta_t \left( \gamma O_t + \lambda W_t \right) Wt+1​=Wt​−ηt​(γOt​+λWt​)
