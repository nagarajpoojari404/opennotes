Activation Functions

Activation functions introduce non-linearities into neural networks, enabling them to approximate complex, non-linear functions (Universal Approximation Theorem). Without non-linear activations, stacking linear layers W2(W1x+b1)+b2W_2(W_1 x + b_1) + b_2W2​(W1​x+b1​)+b2​ collapses mathematically into a single linear transformation (W2W1)x+(W2b1+b2)(W_2 W_1)x + (W_2 b_1 + b_2)(W2​W1​)x+(W2​b1​+b2​).

1. Classical Sigmoidal Activations

These squash inputs into a bounded range. While historically popular, they suffer from severe gradient saturation in deep networks.

Sigmoid (Logistic)

Maps real-valued inputs into the range (0,1)(0, 1)(0,1):

σ(x)=11+e−x,σ′(x)=σ(x)(1−σ(x)) \sigma(x) = \frac{1}{1 + e^{-x}}, \quad \sigma'(x) = \sigma(x)(1 - \sigma(x)) σ(x)=1+e−x1​,σ′(x)=σ(x)(1−σ(x))
  • Properties: Outputs are strictly positive, differentiable everywhere, and naturally represent probabilities.
  • Limitations:
    • Vanishing Gradients: Maximum derivative occurs at x=0x = 0x=0 where σ′(0)=0.25\sigma'(0) = 0.25σ′(0)=0.25. As ∣x∣\vert{}x\vert{}∣x∣ grows, σ′(x)→0\sigma'(x) \to 0σ′(x)→0. Multiplying many factors ≤0.25\le 0.25≤0.25 down dozens of layers drives backpropagated gradients to zero.
      • Non-Zero-Centered: Since outputs are strictly positive, gradients on incoming weights www in ∂L∂w=∂L∂z⋅x\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \cdot x∂w∂L​=∂z∂L​⋅x all take the same sign as ∂L∂z\frac{\partial L}{\partial z}∂z∂L​, causing zig-zagging gradient dynamics during optimization.
  • Modern Role: Rarely used in hidden layers; standard for binary classification output heads and gating mechanisms (e.g., LSTMs, GRUs, GLUs).

Hyperbolic Tangent (tanh⁡\tanhtanh)

A zero-centered, rescaled variant of the sigmoid squashing inputs into (−1,1)(-1, 1)(−1,1):

tanh⁡(x)=ex−e−xex+e−x=2σ(2x)−1,tanh⁡′(x)=1−tanh⁡2(x) \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = 2\sigma(2x) - 1, \quad \tanh'(x) = 1 - \tanh^2(x) tanh(x)=ex+e−xex−e−x​=2σ(2x)−1,tanh′(x)=1−tanh2(x)
  • Properties: Zero-centered output prevents the systematic directional bias seen in Sigmoid; maximum derivative is tanh⁡′(0)=1.0\tanh'(0) = 1.0tanh′(0)=1.0.
  • Limitations: Still saturates quickly when ∣x∣>2\vert{}x\vert{} > 2∣x∣>2, triggering vanishing gradients in deep feedforward or recurrent chains.
  • Modern Role: Hidden states in classical RNNs/LSTMs, diffusion model conditioning latents, and value-head bounding.

2. Rectified Linear Family

Introduced to overcome vanishing gradients for positive inputs by maintaining a constant unit derivative.

ReLU (Rectified Linear Unit)

The workhorse non-linearity for computer vision and classic multi-layer perceptrons:

  • Strengths:
    • Extreme computational efficiency (single comparison / bit-mask operation).
      • No saturation on the positive regime (gradient=1\text{gradient} = 1gradient=1), which fundamentally unlocked training of deep networks like AlexNet and ResNet.
      • Induces sparse representations by setting negative activations to zero.
  • Limitations:
    • Dying ReLU: If a large gradient pushes weights such that a neuron outputs x<0x < 0x<0 across all training samples, its gradient remains permanently 000. The neuron never updates again.
      • Not zero-centered.

Leaky ReLU

Fixes the “Dying ReLU” problem by assigning a small, fixed negative slope:

LeakyReLU(x)=max⁡(αx,x)(typically α=0.01) \text{LeakyReLU}(x) = \max(\alpha x, x) \quad (\text{typically } \alpha = 0.01) LeakyReLU(x)=max(αx,x)(typically α=0.01)
  • Derivative: α\alphaα for x<0x < 0x<0; 111 for x>0x > 0x>0. Ensures a small non-zero gradient flows through negative states, preventing dormant dead neurons.

PReLU (Parametric ReLU)

Promotes the negative slope α\alphaα to a learnable parameter:

PReLU(x)=max⁡(αx,x) \text{PReLU}(x) = \max(\alpha x, x) PReLU(x)=max(αx,x)
  • Mechanism: α\alphaα is trained alongside network weights via backpropagation (can be channel-shared or per-channel). If α=0\alpha = 0α=0, it behaves as ReLU; if α>0\alpha > 0α>0, it behaves as Leaky ReLU.

3. Smooth & Probabilistic Activations (Modern LLM & Transformer Standard)

These replace the hard non-differentiable kink at x=0x = 0x=0 with smooth curves, empirically yielding better optimization landscapes and downstream perplexity in Transformers.

Softplus

A smooth analytic approximation of ReLU:

Softplus(x)=ln⁡(1+ex),ddxSoftplus(x)=σ(x) \text{Softplus}(x) = \ln(1 + e^x), \quad \frac{d}{dx}\text{Softplus}(x) = \sigma(x) Softplus(x)=ln(1+ex),dxd​Softplus(x)=σ(x)
  • Differentiable everywhere with a smooth derivative equal to the logistic sigmoid.
  • Commonly used to parameterize strictly positive parameters (variances σ2\sigma^2σ2 in VAEs, Gaussian processes).

4. Gated Activations in Large Language Models (GLU Family)

Modern open-weight and proprietary LLMs (Llama 2/3, Mistral, PaLM, Gemma, Qwen) do not apply isolated activation functions inside feedforward blocks. Instead, they use Gated Linear Units (GLUs), splitting linear projections into two paths and multiplying one elementwise by an activated gate.

Standard GLU

GLU(x,W,V,b,c)=(xW+b)⊗σ(xV+c) \text{GLU}(x, W, V, b, c) = (xW + b) \otimes \sigma(xV + c) GLU(x,W,V,b,c)=(xW+b)⊗σ(xV+c)

where ⊗\otimes⊗ denotes elementwise (Hadamard) multiplication. One branch computes a linear representation, while the other serves as a sigmoid controller.

Proposed by Noam Shazeer (2020), replacing the outer sigmoid with smooth activations:

  • Why SwiGLU Dominates LLMs:
    • Multiplicative Interactions: The elementwise product creates bilinear interactions between features, drastically increasing the expressive capacity of the MLP block without adding sequential layer depth.
      • Gradient Routing: The derivative of (f(u)⋅v)(f(u) \cdot v)(f(u)⋅v) routes gradients through both paths simultaneously: ∇x=∇f(u)⋅v+f(u)⋅∇v \nabla_x = \nabla f(u) \cdot v + f(u) \cdot \nabla v ∇x​=∇f(u)⋅v+f(u)⋅∇v Even if one path saturates, the other can pass gradients freely.
      • Standard MLP hidden dimensions in Transformers are typically 4dmodel4d_{\text{model}}4dmodel​; SwiGLU implementations typically downscale the intermediate dimension to 83dmodel\frac{8}{3}d_{\text{model}}38​dmodel​ to maintain equivalent FLOPs and parameter counts while delivering lower perplexity.

5. Multi-Class Normalization Activations

Applied across vector spaces rather than elementwise scalar inputs.

  • Standard across attention score normalization (Softmax(QKT/dk)\text{Softmax}(QK^T / \sqrt{d_k})Softmax(QKT/dk​​)) and token generation heads.
