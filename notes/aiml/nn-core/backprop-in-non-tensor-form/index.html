Backprop in non-tensor form

Backprop in non-tensor form

Here is the same derivation using standard scalar calculus and matrix notation, avoiding tensor indices and Einstein summation.

1. Forward Pass

For a mini-batch of size BBB, input dimension DinD_{\text{in}}Din​, and output dimension DoutD_{\text{out}}Dout​:

  • Input matrix: X∈RB×DinX \in \mathbb{R}^{B \times D_{\text{in}}}X∈RB×Din​
  • Weight matrix: W∈RDin×DoutW \in \mathbb{R}^{D_{\text{in}} \times D_{\text{out}}}W∈RDin​×Dout​
  • Bias vector: b∈R1×Doutb \in \mathbb{R}^{1 \times D_{\text{out}}}b∈R1×Dout​ (broadcast across rows)
  • Scalar loss: L∈R\mathcal{L} \in \mathbb{R}L∈R

The pre-activation matrix ZZZ and activation matrix AAA are:

Z=XW+1Bb Z = XW + \mathbf{1}_B b Z=XW+1B​bA=σ(Z) A = \sigma(Z) A=σ(Z)

At the individual element level, for sample b∈{1,…,B}b \in \{1, \dots, B\}b∈{1,…,B} and feature j∈{1,…,Dout}j \in \{1, \dots, D_{\text{out}}\}j∈{1,…,Dout​}:

zbj=∑k=1Dinxbkwkj+bj z_{bj} = \sum_{k=1}^{D_{\text{in}}} x_{bk} w_{kj} + b_j zbj​=k=1∑Din​​xbk​wkj​+bj​abj=σ(zbj) a_{bj} = \sigma(z_{bj}) abj​=σ(zbj​)

2. Error Matrix (Δ\DeltaΔ)

Let the incoming upstream gradient with respect to the activation matrix be:

G=∂L∂A,where Gbj=∂L∂abj G = \frac{\partial \mathcal{L}}{\partial A}, \quad \text{where } G_{bj} = \frac{\partial \mathcal{L}}{\partial a_{bj}} G=∂A∂L​,where Gbj​=∂abj​∂L​

Using the standard single-variable chain rule for element (b,j)(b, j)(b,j), since abja_{bj}abj​ only depends on zbjz_{bj}zbj​:

Δbj≡∂L∂zbj=∂L∂abj⋅∂abj∂zbj=Gbj⋅σ′(zbj) \Delta_{bj} \equiv \frac{\partial \mathcal{L}}{\partial z_{bj}} = \frac{\partial \mathcal{L}}{\partial a_{bj}} \cdot \frac{\partial a_{bj}}{\partial z_{bj}} = G_{bj} \cdot \sigma'(z_{bj}) Δbj​≡∂zbj​∂L​=∂abj​∂L​⋅∂zbj​∂abj​​=Gbj​⋅σ′(zbj​)

In matrix notation, this is the Hadamard (element-wise) product:

Δ=G⊙σ′(Z) \Delta = G \odot \sigma'(Z) Δ=G⊙σ′(Z)

3. Gradient with Respect to Weights (WWW)

A single weight wijw_{ij}wij​ connects input feature iii to output feature jjj. It influences the loss through every batch item’s pre-activation zbjz_{bj}zbj​ for that specific output jjj:

∂L∂wij=∑b=1B∂L∂zbj∂zbj∂wij \frac{\partial \mathcal{L}}{\partial w_{ij}} = \sum_{b=1}^B \frac{\partial \mathcal{L}}{\partial z_{bj}} \frac{\partial z_{bj}}{\partial w_{ij}} ∂wij​∂L​=b=1∑B​∂zbj​∂L​∂wij​∂zbj​​

From the forward equation zbj=∑kxbkwkj+bjz_{bj} = \sum_{k} x_{bk} w_{kj} + b_jzbj​=∑k​xbk​wkj​+bj​, differentiating with respect to wijw_{ij}wij​ gives:

∂zbj∂wij=xbi \frac{\partial z_{bj}}{\partial w_{ij}} = x_{bi} ∂wij​∂zbj​​=xbi​

Substitute this back into the sum:

∂L∂wij=∑b=1BxbiΔbj=∑b=1B(XT)ibΔbj \frac{\partial \mathcal{L}}{\partial w_{ij}} = \sum_{b=1}^B x_{bi} \Delta_{bj} = \sum_{b=1}^B (X^T)_{ib} \Delta_{bj} ∂wij​∂L​=b=1∑B​xbi​Δbj​=b=1∑B​(XT)ib​Δbj​

Because the row index of XXX matches the row index of Δ\DeltaΔ across the summation over bbb, this is the definition of matrix multiplication between XTX^TXT and Δ\DeltaΔ:

∂L∂W=XTΔ \frac{\partial \mathcal{L}}{\partial W} = X^T \Delta ∂W∂L​=XTΔ
  • Dimensions check: (Din×B)×(B×Dout)=Din×Dout(D_{\text{in}} \times B) \times (B \times D_{\text{out}}) = D_{\text{in}} \times D_{\text{out}}(Din​×B)×(B×Dout​)=Din​×Dout​.

4. Gradient with Respect to Bias (bbb)

Each bias component bjb_jbj​ affects the pre-activation zbjz_{bj}zbj​ across all BBB batch samples:

∂L∂bj=∑b=1B∂L∂zbj∂zbj∂bj \frac{\partial \mathcal{L}}{\partial b_j} = \sum_{b=1}^B \frac{\partial \mathcal{L}}{\partial z_{bj}} \frac{\partial z_{bj}}{\partial b_j} ∂bj​∂L​=b=1∑B​∂zbj​∂L​∂bj​∂zbj​​

Since ∂zbj∂bj=1\frac{\partial z_{bj}}{\partial b_j} = 1∂bj​∂zbj​​=1:

∂L∂bj=∑b=1BΔbj \frac{\partial \mathcal{L}}{\partial b_j} = \sum_{b=1}^B \Delta_{bj} ∂bj​∂L​=b=1∑B​Δbj​

In matrix form, this sums the columns of Δ\DeltaΔ across the batch dimension:

∂L∂b=1BTΔ \frac{\partial \mathcal{L}}{\partial b} = \mathbf{1}_B^T \Delta ∂b∂L​=1BT​Δ
  • Dimensions check: (1×B)×(B×Dout)=1×Dout(1 \times B) \times (B \times D_{\text{out}}) = 1 \times D_{\text{out}}(1×B)×(B×Dout​)=1×Dout​.

5. Gradient with Respect to Layer Input (XXX)

To backpropagate to previous layers, compute the gradient for a single input element xbix_{bi}xbi​. This input affects all pre-activations zbkz_{bk}zbk​ for the same sample bbb across all output units kkk:

∂L∂xbi=∑k=1Dout∂L∂zbk∂zbk∂xbi \frac{\partial \mathcal{L}}{\partial x_{bi}} = \sum_{k=1}^{D_{\text{out}}} \frac{\partial \mathcal{L}}{\partial z_{bk}} \frac{\partial z_{bk}}{\partial x_{bi}} ∂xbi​∂L​=k=1∑Dout​​∂zbk​∂L​∂xbi​∂zbk​​

Differentiating zbk=∑mxbmwmk+bkz_{bk} = \sum_{m} x_{bm} w_{mk} + b_kzbk​=∑m​xbm​wmk​+bk​ with respect to xbix_{bi}xbi​:

∂zbk∂xbi=wik \frac{\partial z_{bk}}{\partial x_{bi}} = w_{ik} ∂xbi​∂zbk​​=wik​

Substitute this into the summation:

∂L∂xbi=∑k=1DoutΔbkwik=∑k=1DoutΔbk(WT)ki \frac{\partial \mathcal{L}}{\partial x_{bi}} = \sum_{k=1}^{D_{\text{out}}} \Delta_{bk} w_{ik} = \sum_{k=1}^{D_{\text{out}}} \Delta_{bk} (W^T)_{ki} ∂xbi​∂L​=k=1∑Dout​​Δbk​wik​=k=1∑Dout​​Δbk​(WT)ki​

Summing over the output dimension kkk corresponds directly to multiplying Δ\DeltaΔ by the transpose of WWW:

∂L∂X=ΔWT \frac{\partial \mathcal{L}}{\partial X} = \Delta W^T ∂X∂L​=ΔWT
  • Dimensions check: (B×Dout)×(Dout×Din)=B×Din(B \times D_{\text{out}}) \times (D_{\text{out}} \times D_{\text{in}}) = B \times D_{\text{in}}(B×Dout​)×(Dout​×Din​)=B×Din​.
