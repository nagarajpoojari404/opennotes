Loss Functions

Loss functions measure the discrepancy between a model’s predictions and actual targets, guiding optimization via backpropagation. In neural networks and large language models (LLMs), they fall into distinct families based on the learning objective: regression, classification, distribution matching, embeddings, and alignment.

1. Regression Loss Functions

Used when predicting continuous numerical targets.

Mean Squared Error (MSE / L2L_2L2​ Loss)

Measures the average squared difference between predictions and targets:

LMSE=1N∑i=1N(yi−y^i)2 L_{\text{MSE}} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2 LMSE​=N1​i=1∑N​(yi​−y^​i​)2
  • Mechanism: Penalizes large errors quadratically, making it sensitive to outliers.
  • Use Cases: Standard regression, image reconstruction (autoencoders), diffusion model score matching / denoising objectives (ϵ\epsilonϵ-prediction).

Mean Absolute Error (MAE / L1L_1L1​ Loss)

Measures the average linear distance between predictions and targets:

LMAE=1N∑i=1N∣yi−y^i∣ L_{\text{MAE}} = \frac{1}{N} \sum_{i=1}^N \vert{}y_i - \hat{y}_i\vert{} LMAE​=N1​i=1∑N​∣yi​−y^​i​∣
  • Mechanism: Constant gradient magnitude (±1\pm 1±1) regardless of error size; robust against extreme outliers.
  • Use Cases: Financial forecasting, sparse signal recovery, image super-resolution where MSE causes excessive blurriness.

Huber Loss & Smooth L1L_1L1​

Blends L2L_2L2​ behavior for small errors with L1L_1L1​ behavior for large errors:

Lδ(y,y^)={12(y−y^)2for ∣y−y^∣≤δδ⋅(∣y−y^∣−12δ)otherwise L_{\delta}(y, \hat{y}) = \begin{cases} \frac{1}{2}(y - \hat{y})^2 & \text{for } \vert{}y - \hat{y}\vert{} \le \delta \\ \delta \cdot \left(\vert{}y - \hat{y}\vert{} - \frac{1}{2}\delta\right) & \text{otherwise} \end{cases} Lδ​(y,y^​)={21​(y−y^​)2δ⋅(∣y−y^​∣−21​δ)​for ∣y−y^​∣≤δotherwise​
  • Mechanism: Differentiable everywhere (unlike pure L1L_1L1​ at zero) while preventing gradient explosions caused by L2L_2L2​ on outliers.
  • Use Cases: Object detection bounding-box regression (e.g., Fast/Faster R-CNN), deep reinforcement learning (DQN value targets).

2. Classification & Probabilistic Losses

Used for discrete categorical prediction and probability estimation.

Binary Cross-Entropy (BCE / Log Loss)

Quantifies divergence between binary ground-truth labels y∈{0,1}y \in \{0, 1\}y∈{0,1} and predicted probabilities y^∈(0,1)\hat{y} \in (0, 1)y^​∈(0,1):

LBCE=−1N∑i=1N(yilog⁡(y^i)+(1−yi)log⁡(1−y^i)) L_{\text{BCE}} = -\frac{1}{N} \sum_{i=1}^N \Big(y_i \log(\hat{y}_i) + (1 - y_i)\log(1 - \hat{y}_i)\Big) LBCE​=−N1​i=1∑N​(yi​log(y^​i​)+(1−yi​)log(1−y^​i​))
  • Mechanism: Steeply penalizes confident, incorrect predictions as y^→0\hat{y} \to 0y^​→0 when y=1y = 1y=1.
  • Use Cases: Binary classification, multi-label classification (treating each label independently with a sigmoid head).

Categorical Cross-Entropy (CCE)

The standard loss for multi-class classification where classes are mutually exclusive:

LCCE=−∑c=1Cyclog⁡(y^c)=−log⁡(y^target) L_{\text{CCE}} = -\sum_{c=1}^C y_c \log(\hat{y}_c) = -\log(\hat{y}_{\text{target}}) LCCE​=−c=1∑C​yc​log(y^​c​)=−log(y^​target​)
  • Mechanism: Evaluated over softmax distributions. Drives the logit of the correct class higher relative to all competing classes.
  • Use Cases: Multi-class classification (ImageNet), next-token prediction in language modeling.

Focal Loss

An adaptive cross-entropy variant addressing severe class imbalance:

LFL=−αt(1−pt)γlog⁡(pt) L_{\text{FL}} = -\alpha_t (1 - p_t)^\gamma \log(p_t) LFL​=−αt​(1−pt​)γlog(pt​)
  • Mechanism: Introduces a modulating factor (1−pt)γ(1 - p_t)^\gamma(1−pt​)γ. When an example is well-classified (pt→1p_t \to 1pt​→1), the modulating factor drops to near zero, down-weighting “easy” examples and focusing gradient updates on hard, ambiguous examples.
  • Use Cases: Dense object detection (RetinaNet), rare token/edge-case classification.

3. Distribution Divergence Losses

Quantify differences between continuous or discrete probability densities.

Kullback-Leibler Divergence (KL Divergence)

Measures information lost when approximating true distribution PPP with distribution QQQ:

DKL(P∥Q)=∑xP(x)log⁡(P(x)Q(x)) D_{\text{KL}}(P \parallel Q) = \sum_{x} P(x) \log\left(\frac{P(x)}{Q(x)}\right) DKL​(P∥Q)=x∑​P(x)log(Q(x)P(x)​)
  • Mechanism: Asymmetric (DKL(P∥Q)≠DKL(Q∥P)D_{\text{KL}}(P \parallel Q) \neq D_{\text{KL}}(Q \parallel P)DKL​(P∥Q)=DKL​(Q∥P)). Heavily penalizes QQQ if it places zero probability where PPP has non-zero mass.
  • Use Cases: Variational Autoencoders (VAEs) as a latent regularization term matching latent distributions to N(0,I)\mathcal{N}(0, I)N(0,I); policy regularization in RLHF.

Jensen-Shannon Divergence (JSD) & Wasserstein Distance

  • JSD: A symmetrized, smoothed variant of KL divergence bounded between [0,log⁡2][0, \log 2][0,log2]: JSD(P∥Q)=12DKL(P∥M)+12DKL(Q∥M),M=12(P+Q) \text{JSD}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}(P \parallel M) + \frac{1}{2} D_{\text{KL}}(Q \parallel M), \quad M = \frac{1}{2}(P + Q) JSD(P∥Q)=21​DKL​(P∥M)+21​DKL​(Q∥M),M=21​(P+Q)
  • Wasserstein (L1L_1L1​ Earth Mover’s Distance): Measures the minimum cost of transporting probability mass from distribution PPP to QQQ. Provides smooth, non-vanishing gradients even when support sets do not overlap.
  • Use Cases: Generative Adversarial Networks (WGAN-GP), distribution matching in domain adaptation.

4. Metric Learning & Contrastive Losses

Used to map semantic similarities into distance metrics within embedding spaces.

Triplet Loss

Enforces relative geometric ordering among an Anchor (AAA), a Positive example (PPP), and a Negative example (NNN):

LTriplet=max⁡(0, ∥f(A)−f(P)∥2−∥f(A)−f(N)∥2+α) L_{\text{Triplet}} = \max\Big(0, \, \Vert{}f(A) - f(P)\Vert{}^2 - \Vert{}f(A) - f(N)\Vert{}^2 + \alpha\Big) LTriplet​=max(0,∥f(A)−f(P)∥2−∥f(A)−f(N)∥2+α)
  • Mechanism: Enforces ∥f(A)−f(N)∥2≥∥f(A)−f(P)∥2+α\Vert{}f(A) - f(N)\Vert{}^2 \ge \Vert{}f(A) - f(P)\Vert{}^2 + \alpha∥f(A)−f(N)∥2≥∥f(A)−f(P)∥2+α, ensuring negative points are separated from positives by at least a safety margin α\alphaα.
  • Use Cases: Face verification (FaceNet), speaker diarization, visual search.

InfoNCE (Noise-Contrastive Estimation)

Extends contrastive estimation to multi-negative settings using a softmax formulation:

LInfoNCE=−log⁡exp⁡(sim(q,k+)/τ)exp⁡(sim(q,k+)/τ)+∑i=1Kexp⁡(sim(q,ki−)/τ) L_{\text{InfoNCE}} = -\log \frac{\exp(\text{sim}(q, k_+) / \tau)}{\exp(\text{sim}(q, k_+) / \tau) + \sum_{i=1}^K \exp(\text{sim}(q, k_i^-) / \tau)} LInfoNCE​=−logexp(sim(q,k+​)/τ)+∑i=1K​exp(sim(q,ki−​)/τ)exp(sim(q,k+​)/τ)​
  • Mechanism: Maximizes mutual information lower bounds between positive representations while repelling randomly sampled negatives across a temperature scaling parameter τ\tauτ.
  • Use Cases: Self-supervised visual representation learning (SimCLR, MoCo), multi-modal alignment (CLIP), text embedding models (E5, BGE).

Auxiliary Losses in LLMs

  • Label Smoothing: Replaces hard one-hot targets yyy with (1−ϵ)y+ϵ∣V∣(1 - \epsilon)y + \frac{\epsilon}{\vert{}V\vert{}}(1−ϵ)y+∣V∣ϵ​, preventing overconfident logit saturation and improving calibration.
  • Z-Loss: Penalizes large partition functions (∑exp⁡(zi)\sum \exp(z_i)∑exp(zi​)) by adding c⋅(log⁡∑exp⁡(zi))2c \cdot (\log \sum \exp(z_i))^2c⋅(log∑exp(zi​))2. Mitigates numerical overflow during FP16/BF16 training.
  • Router Load Balancing Loss (Mixture of Experts): Enforces uniform expert dispatch across tokens in MoE models: Laux=α⋅E∑i=1Efi⋅Pi L_{\text{aux}} = \alpha \cdot E \sum_{i=1}^E f_i \cdot P_i Laux​=α⋅Ei=1∑E​fi​⋅Pi​ where fif_ifi​ is the fraction of tokens routed to expert iii and PiP_iPi​ is the average routing probability assigned to expert iii.

6. LLM Preference Alignment & Post-Training Losses

Used to align LLM behaviors with human or AI-evaluated preferences.

RLHF / PPO Policy Objective

Proximal Policy Optimization trains an actor model πθ\pi_\thetaπθ​ against a learned scalar reward model rψr_\psirψ​:

LPPO(θ)=−E(x,y)∼D[min⁡(rt(θ)A^t, clip(rt(θ),1−ϵ,1+ϵ)A^t)]+β DKL(πθ(y∣x)∥πref(y∣x)) L_{\text{PPO}}(\theta) = -\mathbb{E}_{(x, y) \sim \mathcal{D}} \left[ \min\left(r_t(\theta)\hat{A}_t, \, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\right) \right] + \beta \, D_{\text{KL}}\left(\pi_\theta(y \mid x) \parallel \pi_{\text{ref}}(y \mid x)\right) LPPO​(θ)=−E(x,y)∼D​[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]+βDKL​(πθ​(y∣x)∥πref​(y∣x))
  • Mechanism: Maximizes expected advantage A^t\hat{A}_tA^t​ derived from reward model scores, constrained by a clipped probability ratio rt(θ)=πθ(yt∣x,y<t)πold(yt∣x,y<t)r_t(\theta) = \frac{\pi_\theta(y_t\vert{}x, y_{\lt t})}{\pi_{\text{old}}(y_t\vert{}x, y_{\lt t})}rt​(θ)=πold​(yt​∣x,y<t​)πθ​(yt​∣x,y<t​)​ and a KL divergence penalty to prevent drift from base reference policy πref\pi_{\text{ref}}πref​.
  • Use Cases: Reinforcement Learning from Human Feedback (InstructGPT, Claude alignment).

Direct Preference Optimization (DPO)

Re-parameterizes the Bradley-Terry preference model to eliminate the external reward model and RL loop entirely:

LDPO(θ)=−E(x,yw,yl)[log⁡σ(βlog⁡πθ(yw∣x)πref(yw∣x)−βlog⁡πθ(yl∣x)πref(yl∣x))] L_{\text{DPO}}(\theta) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right] LDPO​(θ)=−E(x,yw​,yl​)​[logσ(βlogπref​(yw​∣x)πθ​(yw​∣x)​−βlogπref​(yl​∣x)πθ​(yl​∣x)​)]
  • Mechanism: Derives an exact closed-form expression for the implicit reward r(x,y)=βlog⁡πθ(y∣x)πref(y∣x)r(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}r(x,y)=βlogπref​(y∣x)πθ​(y∣x)​. Directly increases the probability of the winning completion ywy_wyw​ relative to reference policy while suppressing the losing completion yly_lyl​.
  • Use Cases: Post-training preference alignment in modern open-weight LLMs (Llama 3, Zephyr, Qwen).

Identity Preference Optimization (IPO) & Kahneman-Tversky Optimization (KTO)

  • IPO: Adds a regularizer to prevent DPO from quickly driving implicit rewards toward negative infinity when preferences are noisy or deterministic: LIPO(θ)=E[(log⁡πθ(yw∣x)πref(yw∣x)−log⁡πθ(yl∣x)πref(yl∣x)−τ2)2] L_{\text{IPO}}(\theta) = \mathbb{E} \left[ \left( \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} - \frac{\tau}{2} \right)^2 \right] LIPO​(θ)=E[(logπref​(yw​∣x)πθ​(yw​∣x)​−logπref​(yl​∣x)πθ​(yl​∣x)​−2τ​)2]
  • KTO: Replaces pairwise comparisons (yw,yl)(y_w, y_l)(yw​,yl​) with unpaired binary feedback (“desirable” vs. “undesirable”), maximizing utility functions modeled after Prospect Theory loss aversion.

Group Relative Policy Optimization (GRPO)

Eliminates the separate critic network in PPO by sampling a group of outputs {o1,o2,…,oG}\{o_1, o_2, \dots, o_G\}{o1​,o2​,…,oG​} for a prompt qqq, scoring them with a rule-based or model verifier, and computing normalized advantages across the group:

Ai=ri−mean({r})std({r}) A_i = \frac{r_i - \text{mean}(\{r\})}{\text{std}(\{r\})} Ai​=std({r})ri​−mean({r})​
  • Mechanism: Updates policy weights using group-normalized advantages directly, significantly reducing memory consumption and stabilization issues inherent to actor-critic frameworks.
  • Use Cases: Large-scale reasoning model training (DeepSeek-R1, mathematical and coding RL regimes).
