PPO

Proximal Policy Optimization (PPO) is an on-policy reinforcement learning algorithm designed to balance the sample efficiency and simplicity of first-order gradient descent with the training stability of trust region methods.

The Fundamental Problem PPO Solves

In standard policy gradient methods like REINFORCE, the objective maximizes expected return:

J(θ)=Eτ∼πθ[∑t=0TR(st,at)] J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^T R(s_t, a_t) \right] J(θ)=Eτ∼πθ​​[t=0∑T​R(st​,at​)]

Using the Policy Gradient Theorem, the gradient of this objective with respect to network parameters θ\thetaθ is:

∇θJ(θ)=Et[∇θlog⁡πθ(at∣st)A^t] \nabla_\theta J(\theta) = \mathbb{E}_{t} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \hat{A}_t \right] ∇θ​J(θ)=Et​[∇θ​logπθ​(at​∣st​)A^t​]

Where A^t\hat{A}_tA^t​ is the estimated advantage:

A^t=Q(st,at)−V(st) \hat{A}_t = Q(s_t, a_t) - V(s_t) A^t​=Q(st​,at​)−V(st​)

Standard policy gradients suffer from two core failure modes:

  1. Destructive Policy Updates: A single bad parameter update step can shift the policy into a parameter region where it collects terrible trajectories. Because it is on-policy, the agent cannot easily recover from collapsed performance.
  2. Poor Sample Efficiency: Data collected from trajectory rollouts can only be used for a single gradient update before the policy distribution shifts enough to invalidate the expectations.

Trust Region Policy Optimization (TRPO) solved this by constraining each update using the Kullback–Leibler (KL) divergence between the old and new policies:

max⁡θEt[πθ(at∣st)πθold(at∣st)A^t]s.t.Et[DKL(πθold(⋅∣st)∥πθ(⋅∣st))]≤δ \max_\theta \mathbb{E}_t \left[ \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)} \hat{A}_t \right] \quad \text{s.t.} \quad \mathbb{E}_t \left[ D_{\text{KL}}(\pi_{\theta_{\text{old}}}(\cdot \mid s_t) \parallel \pi_\theta(\cdot \mid s_t)) \right] \le \delta θmax​Et​[πθold​​(at​∣st​)πθ​(at​∣st​)​A^t​]s.t.Et​[DKL​(πθold​​(⋅∣st​)∥πθ​(⋅∣st​))]≤δ

While theoretically sound, TRPO requires computing the Fisher Information Matrix and executing conjugate gradient optimization with second-order approximations, making it computationally heavy and complex to implement. PPO achieves similar stability using only standard first-order backpropagation.

The PPO-Clip Objective

Instead of an explicit hard constraint on KL divergence, PPO defines a probability ratio rt(θ)r_t(\theta)rt​(θ):

rt(θ)=πθ(at∣st)πθold(at∣st) r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)} rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​

At the start of an update epoch, θ=θold\theta = \theta_{\text{old}}θ=θold​, so rt(θ)=1r_t(\theta) = 1rt​(θ)=1. As the policy parameters change, rt(θ)r_t(\theta)rt​(θ) diverges from 1.

The clipped surrogate objective function is defined as:

LCLIP(θ)=E^t[min⁡(rt(θ)A^t, clip(rt(θ),1−ϵ,1+ϵ)A^t)] L^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t \left[ \min\left( r_t(\theta) \hat{A}_t, \, \text{clip}(r_t(\theta), 1 - \epsilon, 1 + \epsilon) \hat{A}_t \right) \right] LCLIP(θ)=E^t​[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]

Where ϵ\epsilonϵ is a hyperparameter (typically set to 0.10.10.1 or 0.20.20.2).

How the Clipping Mechanism Operates

The objective evaluates differently depending on whether the action outperformed or underperformed the baseline:

L^CLIP Behavior

   Positive Advantage (A > 0)          Negative Advantage (A < 0)
        Better Action                       Worse Action

      Objective                           Objective
          ^                                   ^
          |      Clipped                      |
(1+ε)A ---+-----------------        (1-ε)A ---+-----------------
          |    /                              |    /
          |   /                               |   /   Clipped
          |  /                                |  /
        0 +---+-------->                    0 +---+-------->
             1-ε 1 1+ε   r_t                     1-ε 1 1+ε   r_t
  • Positive Advantage (A^t>0\hat{A}_t > 0A^t​>0):
    • The action yielded higher-than-expected returns; the optimization aims to increase πθ(at∣st)\pi_\theta(a_t \mid s_t)πθ​(at​∣st​), which pushes rt(θ)r_t(\theta)rt​(θ) above 1.
      • When rt(θ)>1+ϵr_t(\theta) > 1 + \epsilonrt​(θ)>1+ϵ, the term is clipped to (1+ϵ)A^t(1 + \epsilon)\hat{A}_t(1+ϵ)A^t​.
      • The min⁡\minmin operator ensures the gradient drops to zero for further increases, preventing the update from over-committing to a single sample batch.
  • Negative Advantage (A^t<0\hat{A}_t < 0A^t​<0):
    • The action performed worse than expected; the optimization aims to decrease πθ(at∣st)\pi_\theta(a_t \mid s_t)πθ​(at​∣st​), pushing rt(θ)r_t(\theta)rt​(θ) below 1.
      • When rt(θ)<1−ϵr_t(\theta) < 1 - \epsilonrt​(θ)<1−ϵ, the clipped term is (1−ϵ)A^t(1 - \epsilon)\hat{A}_t(1−ϵ)A^t​.
      • Because A^t\hat{A}_tA^t​ is negative, (1−ϵ)A^t(1 - \epsilon)\hat{A}_t(1−ϵ)A^t​ is numerically larger than rt(θ)A^tr_t(\theta)\hat{A}_trt​(θ)A^t​. The min⁡\minmin operator selects the lower bound (rt(θ)A^tr_t(\theta)\hat{A}_trt​(θ)A^t​), still penalizing overly aggressive decreases while cutting off runaway gradients.

Advantage Estimation: Generalized Advantage Estimation (GAE)

PPO typically relies on Generalized Advantage Estimation (GAE) to compute A^t\hat{A}_tA^t​. GAE provides an explicit bias-variance trade-off using a discount factor γ∈[0,1]\gamma \in [0, 1]γ∈[0,1] and an exponential weight parameter λ∈[0,1]\lambda \in [0, 1]λ∈[0,1].

First, define the temporal difference (TD) residual at time step ttt:

δtV=rt+γV(st+1)−V(st) \delta_t^V = r_t + \gamma V(s_{t+1}) - V(s_t) δtV​=rt​+γV(st+1​)−V(st​)

The GAE estimator A^tGAE(γ,λ)\hat{A}_t^{\text{GAE}(\gamma, \lambda)}A^tGAE(γ,λ)​ accumulates these residuals:

A^t=∑l=0∞(γλ)lδt+lV \hat{A}_t = \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}^V A^t​=l=0∑∞​(γλ)lδt+lV​

In practice, for an episode or rollout batch of length TTT, it is computed backward from step T−1T-1T−1:

A^t=δtV+(γλ)A^t+1 \hat{A}_t = \delta_t^V + (\gamma \lambda) \hat{A}_{t+1} A^t​=δtV​+(γλ)A^t+1​
  • When λ=0\lambda = 0λ=0: A^t=δtV=rt+γV(st+1)−V(st)\hat{A}_t = \delta_t^V = r_t + \gamma V(s_{t+1}) - V(s_t)A^t​=δtV​=rt​+γV(st+1​)−V(st​). This is the 1-step TD advantage, which has low variance but high bias.
  • When λ=1\lambda = 1λ=1: A^t=∑l=0T−t−1γlrt+l−V(st)\hat{A}_t = \sum_{l=0}^{T-t-1} \gamma^l r_{t+l} - V(s_t)A^t​=∑l=0T−t−1​γlrt+l​−V(st​). This matches the empirical Monte Carlo return minus baseline, exhibiting zero bias but high variance.
  • Common practical values are γ=0.99\gamma = 0.99γ=0.99 and λ=0.95\lambda = 0.95λ=0.95.

Complete Training Objective

When the policy network (actor) and the value network (critic) share underlying parameters, or during unified joint optimization, the full loss function maximized at each iteration is:

LtPPO(θ)=E^t[LtCLIP(θ)−c1LtVF(θ)+c2S[πθ](st)] L_t^{\text{PPO}}(\theta) = \hat{\mathbb{E}}_t \left[ L_t^{\text{CLIP}}(\theta) - c_1 L_t^{\text{VF}}(\theta) + c_2 S[\pi_\theta](s_t) \right] LtPPO​(θ)=E^t​[LtCLIP​(θ)−c1​LtVF​(θ)+c2​S[πθ​](st​)]

Where:

  • LtVF(θ)L_t^{\text{VF}}(\theta)LtVF​(θ) is the squared-error loss for the critic: LtVF(θ)=(Vθ(st)−Vttarg)2 L_t^{\text{VF}}(\theta) = \left( V_\theta(s_t) - V_t^{\text{targ}} \right)^2 LtVF​(θ)=(Vθ​(st​)−Vttarg​)2 (Note: Many implementations also clip the value function updates similarly to the policy updates).
  • S[πθ](st)S[\pi_\theta](s_t)S[πθ​](st​) is the entropy bonus of the policy distribution to ensure adequate exploration and prevent early collapse into deterministic policies: S[πθ](st)=−∑aπθ(a∣st)log⁡πθ(a∣st) S[\pi_\theta](s_t) = -\sum_{a} \pi_\theta(a \mid s_t) \log \pi_\theta(a \mid s_t) S[πθ​](st​)=−a∑​πθ​(a∣st​)logπθ​(a∣st​)
  • c1,c2c_1, c_2c1​,c2​ are weighting coefficients (e.g., c1≈0.5c_1 \approx 0.5c1​≈0.5, c2≈0.01c_2 \approx 0.01c2​≈0.01).

Step-by-Step Training Loop

  1. Trajectory Rollout: Run current policy πθold\pi_{\theta_{\text{old}}}πθold​​ across NNN parallel environments for TTT timesteps. Collect trajectories {(st,at,rt,st+1,log⁡πθold(at∣st))}\{ (s_t, a_t, r_t, s_{t+1}, \log \pi_{\theta_{\text{old}}}(a_t \mid s_t)) \}{(st​,at​,rt​,st+1​,logπθold​​(at​∣st​))}.
  2. Compute Values & Advantages:
    • Evaluate state values V(st)V(s_t)V(st​) with the critic network.
      • Compute TD residuals δtV\delta_t^VδtV​ and recursively compute advantages A^t\hat{A}_tA^t​ via GAE.
      • Standardize the batch advantages across minibatches: A^t←A^t−μ(A^)σ(A^)+10−8\hat{A}_t \leftarrow \frac{\hat{A}_t - \mu(\hat{A})}{\sigma(\hat{A}) + 10^{-8}}A^t​←σ(A^)+10−8A^t​−μ(A^)​.
  3. Mini-Batch Optimization:
    • Flatten data of length N×TN \times TN×T.
      • Split data into mini-batches of size MMM.
      • For KKK epochs (typically 3≤K≤103 \le K \le 103≤K≤10):
      • Recompute action probabilities under current parameters θ\thetaθ: πθ(at∣st)\pi_\theta(a_t \mid s_t)πθ​(at​∣st​).
        • Compute ratios rt(θ)=exp⁡(log⁡πθ(at∣st)−log⁡πθold(at∣st))r_t(\theta) = \exp(\log \pi_\theta(a_t \mid s_t) - \log \pi_{\theta_{\text{old}}}(a_t \mid s_t))rt​(θ)=exp(logπθ​(at​∣st​)−logπθold​​(at​∣st​)).
        • Compute LCLIP(θ)L^{\text{CLIP}}(\theta)LCLIP(θ), critic MSE loss, and entropy bonus.
        • Backpropagate the total objective using an optimizer like Adam with learning rate annealing.
  4. Update Baseline: Set θold←θ\theta_{\text{old}} \leftarrow \thetaθold​←θ and repeat the cycle.

The number of models required depends on whether PPO is deployed for standard reinforcement learning (robotics, games, control) or RLHF for Large Language Models (RL with Human Feedback).

1. How Many Models Are Needed?

Standard RL: 2 Functional Models

Standard PPO requires an Actor-Critic architecture:

  1. Actor (Policy Model, πθ\pi_\thetaπθ​): Maps a state sss to an action distribution π(a∣s)\pi(a \mid s)π(a∣s). It selects actions during environment rollouts and is updated via the clipped objective.

  2. Critic (Value Model, VϕV_\phiVϕ​): Maps a state sss to a scalar baseline V(s)V(s)V(s) representing the expected cumulative discounted return. It is updated via mean squared error (MSE) to make advantage estimation accurate.

Implementation Note: These two models can either be implemented as two separate neural networks (most common in complex or continuous action spaces to prevent gradient interference) or as a single shared backbone with two separate output heads (one for actions, one for value).

RLHF / LLM Fine-Tuning: 4 Models

When applying PPO to language models, 4 distinct models are loaded into memory:

  1. Actor / Policy (πθ\pi_\thetaπθ​): The language model being trained. Receives a prompt, generates tokens, and updates its weights via PPO.

  2. Critic / Value Model (VϕV_\phiVϕ​): Initialized from the reward or SFT model, but modified to output a scalar value token-by-token (or for the sequence) estimating expected future rewards.

  3. Reference Model (πref\pi_{\text{ref}}πref​): A frozen copy of the initial supervised fine-tuned (SFT) model. Used to calculate a token-level KL divergence penalty to ensure the policy does not drift too far or degenerate into reward hacking.

  4. Reward Model (rψr_\psirψ​): A frozen model trained on human preference pairs. Evaluates the completed generation and assigns a scalar quality score.

Step-by-Step Execution

Phase 1: Trajectory Rollout (Interaction)

  1. Action Generation: The agent starts in state sts_tst​. The actor network computes the action distribution πθold(a∣st)\pi_{\theta_{\text{old}}}(a \mid s_t)πθold​​(a∣st​).

  2. Sampling & Action Execution: An action ata_tat​ is sampled from this distribution and executed in the environment.

  3. Recording Transitions: The environment returns the immediate reward rtr_trt​ and the next state st+1s_{t+1}st+1​. The transition tuple is cached:

    {st, at, rt, st+1, log⁡πθold(at∣st)}\{s_t, \, a_t, \, r_t, \, s_{t+1}, \, \log \pi_{\theta_{\text{old}}}(a_t \mid s_t)\}{st​,at​,rt​,st+1​,logπθold​​(at​∣st​)}

  4. Batch Accumulation: This interaction runs for a fixed trajectory horizon of TTT steps (often across NNN parallel environments simultaneously, yielding N×TN \times TN×T total transitions).

Phase 2: Advantage & Return Computation

Before training begins on the collected rollout:

  1. Value Evaluation: The critic network evaluates all visited states to produce baseline value estimates:

    v^t=Vϕ(st)\hat{v}_t = V_\phi(s_t)v^t​=Vϕ​(st​)

  2. Temporal Difference Residuals: Compute the 1-step TD errors for all steps:

    δtV=rt+γVϕ(st+1)−Vϕ(st)\delta_t^V = r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)δtV​=rt​+γVϕ​(st+1​)−Vϕ​(st​)

  3. Generalized Advantage Estimation (GAE): Accumulate the residuals backwards from t=T−1t = T-1t=T−1 down to t=0t = 0t=0:

    A^t=δtV+(γλ)A^t+1\hat{A}_t = \delta_t^V + (\gamma \lambda) \hat{A}_{t+1}A^t​=δtV​+(γλ)A^t+1​

    (In LLM workflows, rtr_trt​ includes both the reward model score at the final token and per-token KL divergence penalties against πref\pi_{\text{ref}}πref​).

  4. Target Returns: Target values for the critic are constructed by adding the estimated advantage back to the baseline:

    Rttarget=A^t+Vϕ(st)R_t^{\text{target}} = \hat{A}_t + V_\phi(s_t)Rttarget​=A^t​+Vϕ​(st​)

  5. Advantage Normalization: Across the entire collected batch, advantages are normalized to zero mean and unit variance:

    A^t←A^t−μ(A^)σ(A^)+10−8\hat{A}_t \leftarrow \frac{\hat{A}_t - \mu(\hat{A})}{\sigma(\hat{A}) + 10^{-8}}A^t​←σ(A^)+10−8A^t​−μ(A^)​

Phase 3: The Multi-Epoch Optimization Loop

The fixed dataset of N×TN \times TN×T transitions is shuffled and divided into smaller mini-batches of size MMM. The model iterates over this same rollout dataset for KKK epochs (typically 3 to 10 passes):

  1. Forward Pass on Updated Parameters: For each sample in the mini-batch, pass sts_tst​ through the current parameter states πθ\pi_\thetaπθ​ and VϕV_\phiVϕ​ to obtain:

    • Current log-probability: log⁡πθ(at∣st)\log \pi_\theta(a_t \mid s_t)logπθ​(at​∣st​)

    • Current estimated state value: Vϕ(st)V_\phi(s_t)Vϕ​(st​)

    • Distribution entropy: S[πθ](st)S[\pi_\theta](s_t)S[πθ​](st​)

  2. Compute Probability Ratio:

    rt(θ)=exp⁡(log⁡πθ(at∣st)−log⁡πθold(at∣st))r_t(\theta) = \exp\left( \log \pi_\theta(a_t \mid s_t) - \log \pi_{\theta_{\text{old}}}(a_t \mid s_t) \right)rt​(θ)=exp(logπθ​(at​∣st​)−logπθold​​(at​∣st​))

  3. Compute Clipped Policy Loss:

    LCLIP(θ)=E^t[min⁡(rt(θ)A^t, clip(rt(θ),1−ϵ,1+ϵ)A^t)]L^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t \left[ \min\left( r_t(\theta)\hat{A}_t, \, \text{clip}(r_t(\theta), 1 - \epsilon, 1 + \epsilon)\hat{A}_t \right) \right]LCLIP(θ)=E^t​[min(rt​(θ)A^t​,clip(rt​(θ),1−ϵ,1+ϵ)A^t​)]

  4. Compute Critic Loss: Fit the value function to the target returns:

    LVF(ϕ)=E^t[(Vϕ(st)−Rttarget)2]L^{\text{VF}}(\phi) = \hat{\mathbb{E}}_t \left[ \left( V_\phi(s_t) - R_t^{\text{target}} \right)^2 \right]LVF(ϕ)=E^t​[(Vϕ​(st​)−Rttarget​)2]

  5. Combine & Backpropagate: Sum the losses into a single scalar objective to minimize:

    Ltotal=−LCLIP(θ)+c1LVF(ϕ)−c2S[πθ](st)L_{\text{total}} = -L^{\text{CLIP}}(\theta) + c_1 L^{\text{VF}}(\phi) - c_2 S[\pi_\theta](s_t)Ltotal​=−LCLIP(θ)+c1​LVF(ϕ)−c2​S[πθ​](st​)

    Compute gradients via standard backpropagation, apply gradient clipping (e.g., max⁡∥∇∥≤0.5\max \Vert{}\nabla\Vert{} \le 0.5max∥∇∥≤0.5), and step the optimizer (Adam).

Phase 4: Sync and Discard

  • Once KKK epochs conclude, the old rollout transitions {st,at,rt,… }\{s_t, a_t, r_t, \dots\}{st​,at​,rt​,…} are completely discarded.

  • Update the baseline weights: θold←θ\theta_{\text{old}} \leftarrow \thetaθold​←θ.

  • The updated policy πθ\pi_\thetaπθ​ takes over to gather a fresh batch of trajectories in Phase 1.
